# Rule & Ratio

The Law and the Reasoning Behind It.

Independent Indian legal knowledge, news, research and publishing platform. Future journal: Rule & Ratio Review.

## Development
Use Node.js 22.12+ and npm.
```sh
npm install
npm run dev
npm run build
npm run preview
```
The static output is in `dist/`. See [architecture](docs/architecture.md), [editorial policy](docs/editorial-policy.md), [brand guidelines](docs/design-system.md) and [deployment](docs/deployment.md).

This is a pre-launch foundation. No legal articles or journal issues are published yet. The base layout intentionally includes noindex until the production domain, substantive content and launch SEO checks are ready.
