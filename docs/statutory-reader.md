# RR-015H.4 — Public statutory reader

The Act directory now supports section-number/heading searches, chapter filtering and chapter anchors. Provision pages provide a jump menu, all recorded versions, explicit single-version selection, reference-date matching and two-column comparison (stacked on narrow screens). Without JavaScript all statutory text and links remain available. Reference dates default to the Indian calendar date at page load. Matching uses [effectiveFrom, effectiveUntil) and never automatically matches undated records. The UI states that this is recorded-date matching, not a conclusion about applicability or a certified consolidated text. The comparison is side-by-side wording, not a word-level legal diff. Links and notes are preserved. The URL may accept ?date=YYYY-MM-DD and ?version=version-id; version anchors are also supported.

An optional instruments array in each reviewed statute stores a slug, title, kind (rule, notification, order, regulation, other), jurisdiction, description, source (title, URL, pinpoint), optional issue and effective dates, and linked provisionSlugs. Instruments inherit the act's editorial approval and must be independently checked before inclusion. Unknown references, duplicate IDs, missing pinpoints and invalid date intervals fail publication validation. State filters display only recorded instruments, not an exhaustive jurisdictional law search. The draft Bihar rules research remains outside the public data; enacted-only MSMED versions are not exposed. No published metadata or index settings are changed.

Tests: npm run test:statutes covers calendar and date logic; npm run test:publishing with RR_TEST_BROWSER=1 exercises actual routes, search, filtering, mobile comparison and draft exclusion using a synthetic reviewed record. Synthetic output is cleaned up after tests. Current real MSMED draft remains unpublished and must not be enabled until genuine review.
